はじめて開く人が、最初に読むページ

このページの中身

設定と操作の手順だけをまとめています。どんなアプリかの説明は紹介ページにあります。読みたいところから開いてください。

  1. まず開くURLを開き、ホーム画面へ追加するまで
  2. 保護者の画面の開き方子どもの画面には出していない入り口。先に覚えると早いところ
  3. 最初に決めること1台で使うか家族でつなぐか、読める漢字、見本の宿題の扱い
  4. 宿題を登録する3つの数え方と、「かならず やる」「つぎに やる」「まいにち」の分け方
  5. 子どもが毎日すること「やった！」を押して、終わったところを選ぶまで
  6. 2本のバーの見かた間に合いそうかを、どこで読み取るか
  7. 保護者がすること進み具合の確認と、80文字までのひとこと
  8. 家族の端末をつなぐ合言葉とQRコードの手順、合言葉の扱いの注意
  9. データの置き場所端末の中、クラウド、書き出したファイルの違い
  10. よくある質問費用、学年、機種変更、合言葉を忘れたときなど

まず開く

次のURLを、ふだん子どもが触る端末で開きます。iPadでもiPhoneでもパソコンでもかまいません。

https://moyashimisosoup.github.io/shukudai-notebook/

iPhoneとiPadでは、Safariの共有ボタンから「ホーム画面に追加」できます。 次からは、ホーム画面のアイコンだけで開けます。

先に覚えること — 保護者の画面の開き方

子どもの画面に、設定へ行くボタンはありません。押し間違いを減らすためです。開き方は2つあります。

  • 画面いちばん上のタイトルを5回続けてタップする
  • 同じところを2秒押しつづける

URLの末尾に #settings を付けても同じ画面が出ます。よく使うならブックマークしておくと早いです。

設定や宿題の登録、見本の宿題の削除は、保護者の画面から行います。

最初に決めること

1台で使うか、家族でつなぐか

「こどもだけでつかう」を選ぶと、名前・宿題・記録はその端末の中だけに残ります。 1台しか使わないならこれで足ります。あとから家族でつなぐこともできます。

名前と、読める漢字

「すべてひらがな」から「小学6年生まで」、それに「漢字のまま」の中から選びます。 子どもの画面では、まだ習っていない漢字がひらがなに変わります。保護者の画面はふつうの漢字のままです。

見本の宿題をどうするか

最初は「なつスキル」「読書ゆうびん」といった見本の宿題が入っています。 お子さんが学校から持ち帰った宿題ではありません。開くと案内が出るので、どちらかを選んでください。

  • 消す — 見本を全部消して、ゼロから登録し直す
  • このまま使う — 名前と数だけ書きかえる。項目を作る手間が省けます

消す操作ができるのは保護者の画面だけです。子どもの画面には「おうちの人が消せます」という案内だけが出ます。

宿題を登録する

保護者の画面の「宿題」から登録します。数え方は3つあり、宿題の形に合うものを選びます。

  • 番号・かず — ドリルの①〜⑭、プリント6枚、読書20冊。画面には「つぎは ⑦」と出ます
  • だんかい — 自由研究、観察カード、読書感想文。「つぎは『絵をかく』」と出ます
  • まいにち — 音読、お手伝い、学習アプリ。その日のぶんと、続いた日数が出ます

それぞれを「かならず やる」「つぎに やる」「まいにち」に分けます。 学校から必ず出すように言われているものは「かならず やる」に入れてください。 画面上の「しゅくだい」バーには、毎日分を除くすべての宿題が入ります。

子どもが毎日すること

やることは1つです。カードの「やった！」を押して、最後に終わった番号を選びます。

画面はタブ3つだけです。「のこりの しゅくだい」「やったこと」「カレンダー」。 迷うところがないように、これ以上増やしていません。

2本のバーの見かた

画面のいちばん上に、バーが2本並びます。

なつやすみ 54%
しゅくだい 71%

上が夏休みの過ぎたぶん、下が宿題の終わったぶんです。 下が上より先に行っていれば間に合います。 2本を比べると、今のペースで間に合いそうかがわかります。

記録がある程度たまると、いまのペースなら何日に終わるかも出ます。 記録が少ない間は、完了予測を表示しません。

保護者がすること

進み具合を見て、必要なら子どもへひとことを送ります。終わりそうな日、宿題ごとの残り、その日の記録、読んだ本の一覧も確認できます。

それとは別に、80文字までのひとことを送れます。子どもの画面の上のほうに、新しい順に3件まで出ます。 承認を待たせるしくみも、ポイントを配るしくみもありません。 「宿題やった？」と聞く代わりに使ってもらう想定で作りました。

家族の端末をつなぐ

子どものiPadと保護者のiPhoneで同じ記録を見たいときに使います。

  1. 保護者の画面の共有設定で、合言葉を作ります。16文字のものが自動で出ます
  2. そこに出るQRコードか招待リンクを、もう一方の端末で読み取ります

つないだあとは、どちらで記録しても自動で合わさります。 通信が切れている間の記録は端末に残り、同じ合言葉のまま再接続すると送信を再開します。送信前に端末のデータを消さないでください。

合言葉は人に見せないでください。 これを知っている人は、その家族の記録を読めます。招待リンクにも合言葉が入っています。 SNSや掲示板に貼らないこと、送る相手を確かめることだけ守ってください。 すべての端末で合言葉を失うと、共有データは復元できません。

「子どもの端末」「保護者の端末」は、開いたときの画面と記録者名を決める設定です。 ロックや利用権限の設定ではありません。合言葉を知る人は、どちらの端末からでも共有データを扱えます。

データの置き場所

家族でつないでいない場合、名前・宿題・記録はその端末の中だけにあります。アプリの閲覧数と表示性能はCloudflare Web AnalyticsでCookieを使わず集計しますが、名前・宿題・記録を解析へ送りません。

つないでいる場合はクラウドを経由します。中身は端末側で暗号にしてから預けているので、 そのままでは読めません。合言葉と鍵をクラウドへ送ることもしていません。 ただし合言葉を知っている人には読めます。守っているのは合言葉だけです。

どちらの場合も、設定画面からデータをファイルに書き出せます。 端末を買いかえる前と、学期の切れめに書き出しておくと安心です。

共有中にファイルを読み込むと、つないだ家族のデータにも反映されます。 読み込む前に、ファイルの日時と件数を確認してください。

よくある質問

お金はかかりますか。

かかりません。広告も課金もありません。個人が作って公開しているもので、途中から有料になる予定もありません。

アプリストアにありますか。

ありません。ブラウザで開いて使います。iPhoneとiPadでは「ホーム画面に追加」すると、 アプリと同じようにアイコンから起動します。

何年生向けですか。

小学校の低学年を考えて作りました。表示は「すべてひらがな」から「小学6年生まで」、それに「漢字のまま」の中から選べます。

夏休み以外にも使えますか。

使えます。期間は設定で変えられるので、冬休みにも、週ごとの宿題にも使えます。

子どもが設定を触ってしまいませんか。

子どもの画面から設定へ行くボタンはありません。タイトルを5回タップするか2秒押しつづける必要があります。 子どもが誤って開きにくい入り口にしています。

間違えて記録してしまいました。

同じカードから入れ直せます。番号を戻すことも、0に戻すこともできます。 記録そのものは、保護者の画面の「今日の記録」から1件ずつ消せます。

子ども用の端末がありません。

保護者の端末1台だけでも使えます。その場合は家族でつなぐ設定をせず、そのまま使ってください。

記録を他人に見られませんか。

家族でつないでいなければ、端末の外に出ません。つないでいる場合も、中身は暗号にしてから預けています。 見られるとしたら合言葉が漏れたときです。

しばらく使わないと消えますか。

オンライン共有データは、どの端末からも90日間更新がないと削除対象になります。自動削除ではなく、管理者が対象を確認して削除します。予告メールはありません。見るだけでは期間は延びません。端末だけのデータと書き出したファイルは対象外です。

機種を変えるときはどうしますか。

家族でつないでいれば、宿題・進捗・記録・家族共通の設定は同じ合言葉で戻ります。新しい端末の役割と呼び名は選び直します。端末ごとの読みものの履歴は移りません。つないでいない場合は、古い端末で書き出したファイルを新しい端末で読み込んでください。

合言葉を忘れたら戻せますか。

同じ共有データへは戻せません。まだ接続中の端末があれば、そこから招待リンクを作れます。どの端末にも残っていない場合は、新しい合言葉で始め、書き出したファイルがあれば読み込んでください。

端末を一覧から外すと、その端末は見られなくなりますか。

一覧から外しても、アクセス禁止にはなりません。合言葉を入れ直すと再参加できます。端末の紛失や招待リンクの誤送信で閲覧を止めたい場合は、データを書き出してから共有を解除し、新しい合言葉で共有を作り直してください。

Safariとホーム画面のアイコンは同じデータですか。

iPhoneとiPadでは別の端末として保存されます。Safariで使い始めてからホーム画面へ追加した場合は、ホーム画面版で同じ合言葉を読み込むか、書き出したファイルを読み込んでください。

共有中にバックアップを読み込むとどうなりますか。

読み込んだ宿題・設定・記録で現在の内容を置き換え、つないだ家族の端末にも反映します。古いファイルや別の家族のファイルでないか、確認画面の日時と件数を見てから進めてください。

共有する端末の版が違っても使えますか。

全端末を最新版にそろえてください。保護者画面の端末一覧に「古い」と出た端末は、その端末の「アプリ情報」から更新します。

共有データが削除されたあと、戻せますか。

同じ合言葉では戻せません。書き出したファイルがあれば、新しい合言葉で始めてから読み込めます。

動きがおかしいときは。

まず画面を読み込み直してください。iPhoneとiPadは古い内容を強く覚えているので、 ホーム画面のアイコンから開いている場合は、一度アプリを終了してから開き直すと直ることがあります。 それでも直らないときは、GitHubのIssuesに書いてください。

自分で改造したり配ったりできますか。

できます。プログラムはApache-2.0、中に入っている文章と図はCC BY 4.0です。 表示のしかたは LICENSE、LICENSE-CONTENT.md、NOTICE に書いてあります。

画面写真はすべてお試し用の中身で撮ったものです。実在の家族の記録は入っていません。
データや共有に関する説明の訂正は 変更履歴 に記録しています。
ここに書ききれない細かい仕様は README にあります。
