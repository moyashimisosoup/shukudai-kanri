# 学年別漢字配当表の出どころ

[assets/kanji.js](../assets/kanji.js) の `KANJI_G1`〜`KANJI_G6` は、
**小学校学習指導要領（平成29年告示）別表 学年別漢字配当表**です。

記憶で書いていません。以下のとおり、独立した2つの経路で作って突き合わせ、
**1文字も違わないこと**を確認してから入れています。

## 出典

| | |
|---|---|
| 原典 | 小学校学習指導要領（平成29年告示）第2章第1節 国語 別表 |
| 取得元 | https://www.mext.go.jp/content/20230120-mxt_kyoiku02-100002604_01.pdf |
| 該当ページ | PDF の 44〜47ページ（紙面ノンブル 42〜45） |
| 取得日 | 2026-08-11 |

平成29年告示版です。都道府県名の20字が第4学年へ移った改訂が入っており、
字数は 80 / 160 / 200 / 202 / 193 / 191 の計1,026字。**改訂前は
200 / 185 / 181 で合計1,006字**なので、字数を見れば版を取り違えていないか分かります。

なお法令・告示は著作権法第13条により著作権の目的となりません。

## 作りかた（2経路）

**経路A：原典の目視**

該当ページは PDF の中で画像になっていて、`pdftotext` では1文字も取り出せません
（44〜47ページの抽出文字数は 0）。そこで pypdfium2 で PNG に描き出し、
表を1行ずつ読み取りました。

**経路B：機械可読な第三者データ**

[KANJIDIC2](http://www.edrdg.org/kanjidic/kanjidic2.xml.gz)（EDRDG）の
`<grade>` 1〜6 を抜き出しました。これは同じ配当表を機械可読にしたものです。

**突き合わせ**

A と B を集合として比較し、6学年すべてで差分ゼロでした。
さらに小1・小2は、**このリポジトリに以前から入っていた240字とも完全一致**しています。
出どころの違う3つが一致しているので、単独の読み取りミスは残っていません。

KANJIDIC2 は突き合わせにだけ使い、同梱していません。入っている文字列は
原典（告示）から来たものです。

## 検算のしかた

字数はテストで見ています。

```bash
npm test
```

`assets/kanji.js` の各定数について、次を確かめています。

- 字数が 80 / 160 / 200 / 202 / 193 / 191 で、合計1,026字であること
- 同じ学年の中に重複が無いこと
- 学年をまたいだ重複が無いこと
- 1行が20字であること（末尾の行を除く）

最後の1つは検算というより**目で確かめられるようにするため**の決まりです。
ソースの1行が配当表の1行にそのまま対応するので、PDF と並べれば行単位で照合できます。

## 直すとき

改訂があった場合は、上の PDF を取り直して**経路AとBを両方やり直して**ください。
片方だけ直すと、突き合わせという仕掛けそのものが無くなります。
