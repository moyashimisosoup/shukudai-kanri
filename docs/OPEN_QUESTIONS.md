# 未解決QAと、今後の裁定候補

最終更新: 2026-08-13

対象版: v1.1
目的: FAQの文言だけでは答えを確定できない問題を、実装上の問いとして残す。

優先度は、データ損失・意図しない共有・利用者の誤認・操作の迷いの順で決める。ここにある候補は実装決定ではない。大きな仕様変更は、影響と代替案を確認してから着手する。

## v1.1で対処した項目

| 優先度 | 項目 | 対処 |
|---|---|---|
| 最優先 | PV解析と「端末内だけ」の説明が両立していない | Cloudflare Web Analyticsを維持し、名前・宿題・記録の保存先とは分けて説明した |
| 最優先 | 90日後に自動削除されるように読める | 管理者が対象を確認して削除する現状へ文言を訂正した |
| 高 | 端末の役割が認証に見える | 開いたときの画面と記録者名の設定であり、アクセス制限ではないと画面・ガイドへ追加した |
| 高 | 「解除」がアクセス取消に見える | 「一覧から外す」へ変更し、合言葉で再参加できることを確認画面へ追加した |
| 高 | 共有中のバックアップ読込の範囲が不明 | 家族全体へ反映する警告、書き出し日時、宿題件数、記録件数を確認画面へ追加した |
| 高 | 送信前に閉じた場合の再送保証が弱い | 未送信の種類を端末へ保存し、同じ合言葉で再接続したときに送信を再開するようにした |
| 高 | 「今日やった番号」と「最後に終わった番号」が曖昧 | 「最後に終わった番号を選ぶ」へ統一した |
| 高 | 合言葉紛失、機種変更、削除後の復旧範囲が不明 | 戻るデータと戻らない端末別情報、新しい合言葉とバックアップによる復旧をガイドへ追加した |
| 中 | 漢字設定を学年別と誤認させる | 実際の4択をそのまま表示した |
| 品質 | 紹介画像が件数・一巡を主役にしている | 「たゆたう」の実画面を主役にし、件数の訴求を外した |
| 品質 | スクリーンショットが装飾目的で傾いている | 紹介ページの実画面画像を水平に戻した |

## 最優先で残る問い

### 1. 90日削除を、利用者は事前に知ることができない

- 現状: `lastActivityAt` と `expiresAt` の記録はあるが、30日前・7日前の表示、削除予定日、予告メールは未実装。
- 答えにくいQA: 「いつ消えますか」「消える前に知らせてもらえますか」「見るだけで延びますか」。
- 未決定: 画面を開いたときに残日数を出すか、管理者の確認頻度を何日にするか。
- 最小候補: 保護者の共有欄だけに最終更新日と削除対象予定日を表示する。通知基盤は増やさない。
- 裁定条件: 本番の管理者確認手順、頻度、実行記録を先に定める。

### 2. 削除後、端末内データを消す前に書き出せない

- 現状: 削除墓標を検知すると、端末内の共有データを消して初期設定へ戻す。
- 答えにくいQA: 「削除後に、端末に残っていた記録だけでも救えますか」。
- 未決定: 削除済みデータを端末から書き出す猶予を認めるか。認める場合、削除済み共有へ戻さず新しい共有へだけ復元させる方法。
- 最小候補: 初回の墓標検知時に一度だけJSON書き出しを提示し、その後に初期設定へ進む。
- リスク: 削除要求とデータ救済が衝突するため、実装前に保存方針の裁定が必要。

## 高優先で残る問い

### 3. 紛失端末や誤送信した招待リンクを無効化できない

- 現状: 端末を一覧から外しても、合言葉を手で入れ直せば再参加できる。招待リンクにも合言葉が入る。
- 答えにくいQA: 「紛失した端末を、本当に見られない状態にできますか」。
- 現在の回答: 書き出し、共有解除、新しい合言葉、読込という作り直しが必要。
- 最小候補: コードローテーション機能を増やさず、既存4操作を一つの案内にまとめる。
- 発展候補: 新しい合言葉へ暗号化し直して移す単一操作。ただし失敗時の復旧と全端末更新が必要になるため、大きな仕様変更。

### 4. 別々に使い始めた端末を後からつなぐ結果が分かりにくい

- 現状: 記録はIDごとに合流し、進捗は項目ごとの時刻、設定は後に保存した一式で決まる。
- 答えにくいQA: 「両方の端末に宿題があると、どちらが残りますか」。
- 未決定: 接続前に、接続先と手元の宿題名・更新日時・件数の差をどこまで見せるか。
- 最小候補: 接続確認に「記録は合わせる／宿題と期間は新しい設定になる」の2行と、双方の更新日時だけを出す。
- 避ける案: すべての項目を手動で選ぶ合流ウィザード。小さなアプリの範囲を超える。

### 5. バックアップがどの家族のものか判別できない

- v1.1で追加: 日時、宿題件数、記録件数のプレビュー。
- 残る問い: 同じ件数の別家庭ファイルを見分けられるか。旧形式との互換をどこまで保つか。
- 最小候補: 次回書き出しから、子どもの表示名ではなくランダムな家庭識別子と形式版を含め、読込前に「現在と同じ／別」を表示する。
- 注意: 家庭識別子をCloudflare解析へ送らない。ファイル内と端末内だけで比較する。

### 6. 「クラウドにも保存済み」を利用者が確認できない

- v1.1で改善: 未送信の種類は再起動後も残る。
- 答えにくいQA: 「今閉じても、ほかの端末に届きますか」。
- 未決定: Firestoreへの受付と、別端末での受信のどちらを「同期済み」と呼ぶか。
- 最小候補: 共有欄に「この端末に保存済み／共有先にも保存済み」の2状態だけを表示する。常時トーストや通知は増やさない。

### 7. 51件以上の削除と長期オフライン端末で、古い記録が戻りうる

- 現状: 直近の削除墓標は50件。別に軽量な削除印を300件まで保持する設計があるが、境界条件の保証が不足。
- 答えにくいQA: 「消した記録が戻ることはありますか」。
- 最小候補: 内容のないID印を300件まで確実に残し、「51件削除後に古い端末が参加」の回帰テストを追加する。
- 判断: 家庭向けFAQへ件数を出す前に、実装側で例外を減らす。

### 8. 端末の時計ずれが競合解決へ与える範囲

- 現状: 設定、同じ進捗の訂正、削除の一部は端末時刻を使う。
- 答えにくいQA: 「時計がずれた端末で記録しても大丈夫ですか」。
- v1.1で訂正: READMEの「記録と進捗は影響なし」を削除した。
- 最小候補: 起動時に大きな時計ずれを検知できる場合だけ、保護者画面へ短い注意を出す。常設警告は増やさない。

## 中優先で残る問い

### 9. デザインは家族共通か、端末ごとか

- 現状: 共有中は家族の設定として同期され、テーマ変更は他端末にも届く。
- 答えにくいQA: 「子どもだけネコ、保護者だけノートにできますか」。現状はできない。
- 最小候補: 設定に「家族の端末で同じデザインになります」と一行出す。
- 発展候補: テーマだけ端末設定へ戻す。ただし移行と初回参加処理が変わるため、裁定が必要。

### 10. 飛ばして解く宿題と「最後に終わった番号」

- 現状: 番号nを選ぶと、1からnまで終わった前提の進捗になる。
- 答えにくいQA: 「3番だけ後回しにした場合はどうしますか」。
- 最小候補: FAQで「連続した最後の番号を選ぶ」と答える。
- 発展候補: 飛ばした番号だけを一時的に残す印。個別チェック一覧は操作量を増やすため採用条件を厳しくする。

### 11. 「かならず やる」「つぎに やる」と2本のバーの意味

- 現状: 全体バーには毎日分を除く必須・任意が入り、ペース判定では全体と必須の双方を見る。表示上の「つぎ」とカードの「次にやる」が近い。
- 答えにくいQA: 「つぎにやる宿題も、間に合わせる必要がありますか」。
- 最小候補: 説明上だけ「かならず出す／できたらやる／まいにち」に整理する。実UI名変更は利用中データへ影響しないが、全画像とマニュアルの更新が必要。

### 12. サンプル宿題を消した後に戻せるか

- 現状: 全消去はできるが、その場で件数と復元可否が見えにくい。
- 答えにくいQA: 「いったん消してから、見本だけ戻せますか」。
- 最小候補: 確認画面に見本件数と復元方法を一行追加する。見本カタログ画面は作らない。

### 13. アクセシビリティの公開可能な到達点

- 現状: フォーカス表示、reduced motion、狭幅、色以外の一部手掛かりを実装。スクリーンリーダーと200%拡大の全操作検収は未完了。
- 答えにくいQA: 「スクリーンリーダーで全部使えますか」。断言できない。
- 最小候補: 主要3操作だけをVoiceOver / キーボード / 200%拡大で検収し、未対応操作を公開する。
- 避ける表現: 「誰でも使える」「完全対応」。

## 機能を増やさず洗練できる余地

1. 保護者画面に、最後の共有保存時刻を一行だけ出す。
2. 接続前に、接続先の宿題件数・更新日時だけを見せる。
3. 破壊操作のボタン直下に「この端末だけ／家族の全端末」を固定表示する。
4. 合言葉作成直後に、紙へ控える・端末へ保存する導線を一度だけ出す。
5. 共有版が違うときだけ更新手順を開き、普段はFAQを増やさない。
6. 「最後に終わった番号」「進み具合を直す」「記録を消す」を画面全体で同じ語にする。
7. デザインが家族共通であることを、テーマ選択の直下に短く出す。

## 採用しない方向

- 子ども別プロフィールを増やす
- ポイント、ランキング、連続日数の強調
- 保護者承認を待たせる仕組み
- 常時通知や督促
- AIによる励まし文の自動生成
- 細かな権限ロール
- 多段の合流ウィザード

どれも一般的な学習アプリにはあるが、このアプリの「次にやることを一つ見る」「タップで記録する」という範囲を広げすぎる。必要性が具体的な家庭内の場面で確認できるまで追加しない。
