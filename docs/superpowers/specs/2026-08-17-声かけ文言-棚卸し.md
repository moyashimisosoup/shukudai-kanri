# 声かけ文言の棚卸し（低学年 / 高学年 / 共通）

作成: 2026年8月17日。**裁定用の資料であって、決定ではない。**
対象は `assets/app.js` の `PACE_MESSAGES` / `PACE_MESSAGES_ADULT` / `wording()` の対、
および「切りかえていないのに子どもに向いている文」。

## 0. 先に事実を3つ

1. **幅は余っている。** 上限は見積もり 13.25。低学年側は max **13.25**（ぎりぎり）だが、
   高学年側は max **10.90**。短さは制約ではなく、低学年の文を漢字に置きかえた副作用。
2. **高学年側に幅のテストが無い。** `tests/sync-regression.test.js:2323` は
   `PACE_MESSAGES` だけを見ており、`PACE_MESSAGES_ADULT` は素通り。
   引継ぎには「13.25以下」と書いてあるが、実際には縛られていない。
3. **感嘆符が 32/32。** 高学年側の全文が「！」で終わる。

## 1. 判定の型（この資料で使う記号）

| 記号 | 意味 |
|---|---|
| 体 | 体言止め・動詞なしの断定。「まず〇〇から！」「今から一つずつ！」 |
| 評 | 評価者の口。「よくできたね」「ばっちり」 |
| 借 | 低学年の口語がそのまま漢字文に混ざる。「へいき」「ばっちり」「こつこつ」 |
| 責 | 遅れを負債として名指し。「もどろう」「とりもどそう」「がんばりどき」 |
| 重 | 他の文と内容がほぼ重複 |
| ズ | 低学年側と高学年側で**内容がずれている**（表は「そろえる」と書いてある） |
| ○ | 高学年向けとして通用する。見本にできる |

## 2. 進み具合の一言（32対）

### good ＝ よゆう（全体・必須とも 8pt 以上先行）

|---|---|---|---|
| 1 | よゆうだね！このちょうし！ | 順調だね！この調子！ | 2文とも短く切れていて電文的 |
| 2 | とっても いいペース！ | とても良いペース！ | 体・評 |
| 3 | すすみぐあい ばっちり！ | 進み具合ばっちり！ | 体・評・借 |
| 4 | このまま いこう！ | このまま進もう！ | ○ |
| 5 | こつこつ すすんでいるね！ | 着実に進んでいるね！ | ○ 過程を認めている。見本 |
| 6 | よく つづいているね！ | 今のペースで続けよう！ | **ズ**（子＝ねぎらい／大＝後押し） |
| 7 | しっかり すすんでいるね！ | しっかり進んでいるね！ | 重（5と同義） |
| 8 | ここまで よく できたね！ | ここまでよくできたね！ | 評（高学年には上から） |

### focus ＝ 全体は先行、必須が遅れ

| # | 低学年 | 高学年 | 点検 |
|---|---|---|---|
| 1 | まず「かならず やる」から！ | まず「必ずやる」から！ | 体（「次は〇〇。」型の中心） |
| 2 | だいじな宿題を さきに！ | 大事な宿題を先に！ | 体 |
| 3 | 「かならず やる」を ひとつ！ | 「必ずやる」を一つ！ | 体 |
| 4 | きょうは だいじな宿題から！ | 今日は大事な宿題から！ | 体・重（2と同義） |
| 5 | まずは ひとつ すすめよう！ | まずは一つ進めよう！ | ○ |
| 6 | だいじな宿題に もどろう！ | 大事な宿題に もどろう！ | 責（サボっていた前提を読ませる） |
| 7 | さきに ひとつ かたづけよう！ | 先に一つ かたづけよう！ | ○ |
| 8 | まずは だいじなほうから！ | まずは大事な方から！ | 体・重（1,4と同義） |

**この状態が最も傷んでいる。** 8文中5つが体言止め、4つが「まず大事なほうから」の言い換え。

### hurry ＝ 必須が遅れ（−6pt 以下）

ユーザーが挙げた「期限が半分以上過ぎて未着手」はここ。

| # | 低学年 | 高学年 | 点検 |
|---|---|---|---|
| 1 | きょうは がんばりどき！ | 今日はがんばりどき！ | 責（遅れている子に追い打ち） |
| 2 | いまから ひとつずつ！ | 今から一つずつ！ | 体 |
| 3 | すこしずつ とりもどそう！ | 少しずつ とりもどそう！ | 責（遅れを負債と名指し） |
| 4 | まずは できるところから！ | まずはできる所から！ | 体（向きは良い） |
| 5 | ひとつ えらんで はじめよう！ | 一つ選んで始めよう！ | ○ 選択＋着手。見本 |
| 6 | ちいさく すすめば へいき！ | 小さく進めば へいき！ | 借・根拠のない断言 |
| 7 | きょうの ひとつを やろう！ | 今日の一つをやろう！ | ○ |
| 8 | できるところから やろう！ | できる所からやろう！ | 重（4と同義） |

**欠けているもの:** 「着手そのものを目標にする」文が 1つも無い。
「少しでも手をつけることが大切」型（＝ユーザーの案）は現在ゼロ。

## 3. 記録シートの呼びかけ（wording() の対）

| 箇所 | 低学年 | 高学年 | 点検 |
|---|---|---|---|
| 番号式の説明 | やった ところを おしてね。そこまで ぜんぶ できたことに なるよ。 | やった 所を おしてね。そこまで 全部 できたことに なるよ。 | 「〜てね」「〜なるよ」が保育的。**分かち書きが残る** |
| 毎日式の目標 | 1日の めあては | 1日の 目当ては | 分かち書きが残る。「目当て」は学校語 |
| しあげ | ぜんぶ おわったね！ できた ところを おしてね。 | 全部 終わったね！ できた 所を おしてね。 | 同上 |
| 観察 | わかるところだけで いいよ。答えごとに保存でき、次に開いたときも残るよ。 | 分かる 所だけで いいよ。答えごとに残せて、次に開いたときも残るよ。 | 「残せて／残るよ」の重複。低学年側だけ「保存」の漢字 |
| 文章の書き出し | 今日のはっけん、今おもっていること、…なんでもかいてみよう。 | 今日の発見、今思っていること、…なんでも書いてみよう。 | ○ |

## 4. スタンプ（既に集約済み・現状で妥当）

| 場面 | 低学年 | 高学年 |
|---|---|---|
| 数・段階を進めた | できた！ | できた |
| 全部終わった | ぜんぶ できた！ | 完了！ |
| 作文を書いた | かけたね！ | できた |
| 本を読んだ | よめたね！ | できた |
| 本を読み終えた | ぜんぶ よんだ！ | 完了！ |
| 記録を直した | なおしたよ | なおした |

唯一の点検：高学年で「完了！」だけが感嘆符を持つ。

## 5. 切りかえていない ＝ 高学年にも子ども語のまま出る文

「切りかえるのは呼びかけだけ、骨組みは変えない」という規則が、
実際には**呼びかけの一部だけ**を切りかえている。

| 場所 | 文 | なぜ引っかかるか |
|---|---|---|
| `.lab`（段階式） | できた ところを おしてね | すぐ下の hint は切りかえるのに、この行は子ども語のまま |
| `.lab`（番号式） | どこまで やった？ | 明らかに呼びかけ。骨組みではない |
| `.lab`（毎日式） | きょうは どのくらい できた？ | 同上 |
| `.lab` | さいごの しあげ／かんさつ してみよう | 見出しだが呼びかけの口調 |
| `selSayText` | まだ ひとつも やっていない／〜まで ぜんぶ できた！ | 選択の言い当て。呼びかけそのもの |
| `starSay` | とても おすすめ／ふつう／まだ えらんでいない | 同上 |
| `dailyMorePrompt` | 6回以上のときは、何回できたか 入れてね。 | 「入れてね」 |
| 保存済みの印 | ✓ ほぞんずみ | |
| `placeholder` | かいてみよう | |
| `forecastText` | かんりょうよそく：いまのペースだと／すすむと めやすが でるよ | 子ども画面かどうかで分けており、**学年を見ていない** |
