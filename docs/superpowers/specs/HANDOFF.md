## 判断基準

憲章 [`docs/PRODUCT_POLICY.md`](../../PRODUCT_POLICY.md) の **5章「操作の手ごたえと確認」** が本文。要点だけ:

- 安全な操作に確認を挟まない（確認は「危険がある」と読まれる）
- 待てるものは聞かない（継ぎ目まで待てば中断の選択肢も要らない）
- 平常時の画面に要素を足さない
- 「元に戻す」は時系列ではなく場所（欄ごと）で持つ
- 失われないものを「失われる」と警告しない
- 既にある事実で判定できるなら、覚えることを増やさない
- 規則を破るときは規則を消さず、**理由つきの例外**として登録する

## 検査の型（実際に取り逃がした事象から）

- 単体で切り出す検査は**呼び出し経路の欠落を見つけられない**。「関数が正しい」と
  「関数が呼ばれる」は別。実機で通すまで分からない
- テストのハーネスが**既定値で本番の条件を回避していないか**疑う
- 検査スクリプトの結果は**数で妥当性を確かめる**（配当表の抽出ミスは字数で気づいた）
- 検査を足したら、**落ちるべきものが落ちるか**を一度試す。通っているだけの検査は
  効いている証拠にならない（配当外の字の混入、案内文の巻き戻しで実際に確認した）
- CSSでは「規則が**在る**」と「規則が**勝つ**」が別。規則の存在だけを見るテストは
  後から書かれた上書きに無力で、実際 v1.3.21 の作業中に
  **テスト全通過のまま実機だけ直っていない**状態を踏んだ（`.set-task-move` が
  後方の `@media (max-width:639px)` に負けていた）。幅ごとの指定は
  **いちばん後ろのブロックに置き**、「後ろに戻す指定が無いこと」も併せて見る

## 直近で入れた仕組み（触るとき注意）

| 仕組み | 場所 | 注意 |
|---|---|---|
| 版の自動取り込み | `checkForNewVersion` / `adoptNewVersionIfSafe` / `noticeAdopted` | 起動と前面復帰の継ぎ目でだけ動く。経過時間で止めない（起動直後に走るため無効化される）。ループ防止は `K_UPDATE_RELOADED_FOR` |
| 宿題編集の取り消し | `configTaskBase` / `TASK_FIELD_KEYS` / `refreshTaskRow` | 基準は**最初の変更の直前**に控える（`toggle` では取りこぼす）。`change` の分岐は `saveCfg()` だけで描き直さないものが多く、`refreshTaskRow` を呼ばないと印が出ない |
| 学年で言い方を変える | `grownUpWording()` / `wording()` / `PACE_MESSAGES_ADULT` | 小4以上と9（漢字のまま）が対象。**大人側の漢字は小4までの配当**に収める。例外は `STAMP_KANJI_EXCEPTIONS`（いまは「了」＝スタンプ「完了！」のみ） |
| 書きかけの保護 | `sheetInputsChanged` / `confirmLeaveSheet` / `popstate` | シートを開くとき履歴を1つ足す。閉じたら `history.back()` で回収 |
| 長い文字列の出し分け | `paceVerdictSizeClass` / `appTitleSizeClass` | 1行を保ったまま長い文だけ縮める型。文字幅は字ごとの重みで見積もる（空白.35、約物.55）。CSS側は `clamp()` で画面幅にも追従させ、**幅ごとの @media より後ろに置いて上書きする** |

## 文字の切れ（…）についての裁定（2026-08-17 に全数を実測）

`text-overflow:ellipsis` を使う7か所を 320px の実機で測り、直す／残すを分けた。
**基準は「文言を自分たちが書いているか」**。自分たちの文なら入る形にする責任があり、
利用者が入れた文字列は長さを保証できないので … を残す。

| 箇所 | 実測 | 裁定 |
|---|---|---|
| `.set-task-summary strong`（設定の宿題名） | 欄が108pxしかなく実データ16件中ほぼ全部が62〜114px超過 | **直した**。`@media (max-width:639px)` で名前に1行まるごと使わせ、種類・件数・並べかえは下の段へ。16件すべて超過0 |
| `.topband-title`（上帯の題名） | 名前4文字（「さくらこの夏休みの宿題」）で17px超過 | **直した**。`appTitleSizeClass` で11文字以上を縮める。320pxで12文字まで収まる。下限14pxは隣の日づけ（13px）より大きく保つ線。13文字以上は … のまま（帯を2行にしないための割り切り） |
| `.sec-head h2`（子ども画面） | 最長「まいにち すこしずつ」で超過0 | 残す。文言は自分たちのもので現状は入る。大人側は既に折り返し済み |
| `.pace-verdict` | 全文言で超過0（`paceVerdictSizeClass` が効いている） | 残す。… は見積もりが外れたときの気づき用 |
| `.parent-head h2` | 3種類の固定文、超過0 | 残す。縦に割れると帯の丈が伸びるため、意図して … にしてある |
| `.free-said`（自由記述カードのメモ1行目） | 箱が246pxのところ**475pxに膨らみ**カード外へ。要素自身は溢れていないので**…すら出ない** | **直した**。`.free-body{ min-width:0 }`。カードは grid の `1fr` で最小幅が min-content のため、nowrap の中身がトラックを押し広げていた |
| `.parent-share-short`（保護者ページ上部の共有バッジの狭い画面用の文） | 「子ども端末の接続待ち」が**20px超過**、「ほかの端末と共有中」が9px超過 | **直した**。既にある「：設定」と同じ「：〈短い語〉」の形にそろえた（`：接続待ち`／`：ほかの端末`／`：子ども`／`：〈名前〉`）。名前だけは長さを約束できないので … に任せる |

**この2件は最初「残す」と誤って裁定した。**画面に出ていないことを理由に実測せず、
設計上の省略だろうと推測したため。指摘を受けて出し方（`#settings` を開く／
実カードに差し込む）を用意して測ったら、どちらも実際に壊れていた。
**出ていない画面は「問題が無い」ではなく「まだ見ていない」。**

## 次にやること：高学年向けの呼びかけ文の調整

### この仕組みが何をしているか

「読める漢字」で **小4以上**または**漢字のまま（9）** を選んだ家では、
子どもへの**呼びかけの文だけ**を 少し大人びた言い方に 切りかえる。

| もの | 場所 |
|---|---|
| 対象かどうかの判定 | `grownUpWording()`（`g >= 4 \|\| g === 9`） |
| 文の選択 | `wording(child, adult)` |
| 進み具合の一言 | `PACE_MESSAGES` ／ `PACE_MESSAGES_ADULT`（good/focus/hurry/steady × 各8文） |
| スタンプ | `stamp(wording('できた！', 'できた'))` の形で各所に散っている |

### 触る前に知っておくこと（すべてテストで縛ってある）

1. **大人側の漢字は 小4までの配当に収める。** 配当外の字を混ぜるとテストが落ちる。
   落ちたら 言い換えるか、`STAMP_KANJI_EXCEPTIONS` に**理由つきで**登録する
   （いまは「了」＝スタンプ「完了！」のみ）。規則を消して通すのは無し
2. **各状態8文ずつ。** 数を変えると「同じ日は同じ文言」の仕組み（`day % rows.length`）が崩れる
3. **切りかえるのは呼びかけだけ。** タブ名・見出し・ボタン・設定画面は 子ども向けのまま
4. **指すものが無い比喩を入れない。**「いいリズムだね」は何のリズムか無く、削除済み
5. **320pxで1行に収まる長さ。** 見積もり幅 13.25 以下（`visualWidth`）。
   これを超えると テストが落ちる。長い文は `paceVerdictSizeClass` が自動で縮めるが、
   縮めても限度がある

### 進め方

```bash
node --test --test-name-pattern '大人びた言い方' tests/sync-regression.test.js
```
