# 記録シートに「これまでの きろく」を出す

作成日：2026年8月16日

## 解決する問題

記録シートには性質の異なる2種類の入力欄が、同じ見た目で縦に並んでいる。

| 欄 | 保存の寿命 | 実装 |
|---|---|---|
| 任意質問の答え | 上書きされ、次回も残る**1つの状態** | `state.questionAnswers[t.id]` |
| メモ欄 | 記録するたびに足される**履歴** | `state.logs[].memo` |

どちらも同じ `textarea` として並ぶため、区別する手がかりが画面上にない。自由研究の
メモ欄ラベル「しらべること・わかったこと」は積み上げていく内容に読めるため、
上の質問欄と混同が起きる。

ラベル文言の変更だけでは解決しない。`config.tasks` は利用者の設定として保存・同期される
ため（[app.js:410](../../../assets/app.js)）、[data.js](../../../assets/data.js) の
`memoLabel` 既定値を書き換えても既存の家庭には届かないからである。

## 方針

**構造で示す。** メモ欄の直下に、その課題の過去のメモを新しい順に並べる。

上は答えが1つ残るだけ、下は書くたびに下へ積まれる、という**形の非対称**が画面に出ることで、
注意書きを増やさずに性質の違いが伝わる。小学2年生が読む画面であり、説明文の追加は
読む負担を増やすだけで効きにくい。ラベルに依存しないため、既存の家庭にも移行処理なしで届く。

## 部品

`recentLogsHTML(t)` を1つ作り、次の2か所で使う。

| シート | 現状 | 変更後 |
|---|---|---|
| 通常（count / step / daily） | 過去の記録を出していない | メモ欄の直下に差し込む |
| 自由記録（`isFree`） | `freeTodayHTML()` が今日の分だけを出す | `recentLogsHTML()` に置き換える |
| 本の記録（`isBook`） | 対象外 | 変更しない |

`freeTodayHTML()` を置き換えるのは、今日の分しか出ないため日をまたぐと空になり、
通常シートと同じ問題を抱えているからである。1つの部品に寄せて全課題で見え方をそろえる。

本の記録シートを対象外とするのは、1冊ずつが独立した項目であり、一覧が保護者ページに
既にあるためである。

## 表示仕様

- 見出しは「これまでの きろく」
- **直近3件は常時表示。** 4件目以降は `<details>` の「もっと 見る」に折りたたむ
- 各件は「日付＋時刻」と「メモ本文」を出す。日付を入れるのは、日をまたぐ課題で
  積み重なりが見えるようにするため
- **メモが空の記録は出さない。** 進捗だけ付けた記録が並ぶと、何も書いていない行が
  ノイズになる
- **1件も無ければブロックごと出さない。** 初回に空の見出しだけが出る状態を避ける
- 折りたたみ内は**最大50件**。超えた分は「ふるい きろくは『やったこと』で 見てね」と案内する

メモ欄のラベル（`memoLabel`）は各家庭の現行値のまま変更しない。

## データの流れ

```
state.logs
  → taskId で絞る
  → memo が空でないものだけ残す
  → at の新しい順に並べる
  → 先頭3件（常時表示）／ 4〜50件目（折りたたみ）／ 51件目以降（案内文に置換）
  → HTML
```

読み取り専用であり、`state` を書き換えない。同期にも影響しない。

## 表示負荷

記録は全体で3000件が上限（[app.js:4301](../../../assets/app.js)）。`<details>` の中身は
開くまでレイアウトされないため、通常規模（自由研究で数十件）では体感差が出ない。
毎日型の課題が記録を独占した最悪ケースを避けるため、折りたたみ内にも50件の上限を設ける。

## 異常時の扱い

- `state.logs` が未定義・配列でない → 空として扱い、ブロックを出さない
- `at` が不正な日付 → その件は日時を出さずメモ本文だけ出す。記録そのものは隠さない
- メモ本文は既存の `esc()` を通す。改行は現行のメモ表示と同じ扱いにそろえる

## テスト

`tests/sync-regression.test.js` に追加する。

- 直近3件が常時表示され、4件目以降が折りたたみに入る
- メモが空の記録が一覧に出ない
- 1件も無いときはブロックごと出ない
- 折りたたみ内が50件で打ち切られ、案内文が出る
- 自由記録シートでも同じ部品が使われる（`freeTodayHTML` が残っていない）

## 対象外

次の2件はこの仕様に含めない。

- **v1.3.14 で旧記録の任意質問の答えが入力欄に出ない不具合。** 根本原因が未確定。
  「この答えは保存ずみです」が空欄で出るのは v1.3.12 のみで、その経路は書き込み前に
  return するため専用欄の行は作られない。調査を継続する
- **iPad の端スワイプによるページ遷移で入力中の内容が失われる問題。** 入力中の内容が
  あるときに確認を出す案を、この作業のあとに別途設計する
