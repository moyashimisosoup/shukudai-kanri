v1.1 2026年8月13日

説明と、共有時の確認を改めました

v1.0の公開後に、実装と説明を照らし合わせて見つかった問題を優先順に直した版です。全端末を開き直し、保護者画面の端末一覧で古い版が残っていないか確認してください。

今回の対処項目

  1. 最優先｜保存期間の説明オンライン共有データは90日間更新がないと削除対象になります。現状は自動削除ではなく、管理者が確認して削除します。予告メールはありません。
  2. 最優先｜PV解析の明記Cloudflare Web Analyticsによるアプリの閲覧数・表示性能の集計を明記しました。Cookieを使わず、名前・宿題・記録は解析へ送りません。
  3. 高｜共有中のバックアップ読込家族の共有データにも反映されることを確認画面へ追加し、書き出し日時と件数を表示するようにしました。
  4. 高｜端末の役割と「一覧から外す」役割は認証ではないこと、一覧から外しても合言葉で再参加できることを画面内に明記しました。
  5. 高｜未送信の記録送信前に閉じた場合の目印を端末へ残し、同じ合言葉で再接続したときに送信を再開するようにしました。
  6. 高｜合言葉・機種変更・削除後戻るデータと戻らない端末別情報、合言葉を失った場合、共有データ削除後の復旧方法を使い方ページへ追加しました。
  7. 品質｜紹介画像と文章件数を並べる説明をやめ、実際の「たゆたう」の画面を中心に再構成しました。スクリーンショットの傾きもなくしました。
  8. 品質｜紹介ページの組版大きな見出しを意味のまとまりで改行し、文字サイズと行間を調整しました。登録不要の丸い吹き出しは画面画像と重ならない位置へ移し、2本のバーは子ども画面と同じ構成に揃えました。開発者本人の説明も囲んで掲載しました。

v1.0からの大切な訂正

「90日で自動的に消える」ではありません

削除対象の抽出と管理者による削除はありますが、自動削除と事前通知は未実装です。大切な記録は設定から書き出してください。

端末を一覧から外しても、利用停止にはなりません

合言葉を手で入れ直すと再参加できます。紛失端末などのアクセスを止める場合は、共有を作り直します。

バックアップ読込は、この端末だけの操作とは限りません

共有中は、読み込んだ内容が家族の共有データにも反映されます。確認画面で対象を確かめてから進めてください。
