5つの案

どれも画面の全面に出ます。スマホで、上のテーマを切りかえながら見くらべてください。 「しくみ」の行が、その案をほかと分けているものです。

H1

線香花火

静かなのに、いちばん目が離せない。

一点に火の玉が下がり、そこから細い枝が枝分かれしながら伸びます。 牡丹 → 松葉 → 散り菊 と勢いが移り、最後に玉が落ちて終わります。

しくみ：粒が子どもの粒を産む（再帰的な枝分かれ）。ほかの4案には無い。
H2

打ち上げ花火（間と二段咲き）

前の案に足りなかったのは「間」でした。

下から一筋のぼって、いったん何も無くなり、それから開きます。 さらに開いた粒のいくつかが、落ちながらもう一度小さく割れます。

しくみ：上昇 → 空白 → 開花 → 小割 の4段。空白の0.15秒が全部を作る。
H3

柳（しだれ）

点ではなく、線で描く花火。

高いところで開き、長い尾を引きながらゆっくり垂れて落ちます。 粒が丸ではなく筋に見えるので、同じ数でもずっと豪華に見えます。

しくみ：前のコマを消さずに薄める（残像）。丸ではなく軌跡が見える唯一の案。
H4

型抜き花火

円でなくてもいい、と気づく案。

粒が円ではなく、形を保ったまま開きます。 はなまる ◎ ／ ほし ★ ／ ハート の3つを切りかえられます。

しくみ：粒の初速を形の輪郭から取る。全部が同じ速さなので形が崩れない。
H5

文字花火

意外性はこれがいちばん強い。

ふつうに開いたと思ったら、散った粒が引き返して集まり、 「できた！」の形になってから崩れ落ちます。

しくみ：文字を裏の canvas に描いて点を採り、粒をそこへ引き寄せる。開く→集まる→崩れる。

5案を続けて再生

並べると差がはっきりします。

H1 → H2 → H3 → H4 → H5 の順に、間をあけて自動で流します。どれが残るかで選んでください。

見るときのポイント

この5案を分けているもの

  • H1 線香花火… 粒が粒を産む。ほかの4案は最初に決めた数だけで終わる。
  • H2 打ち上げ… 時間に段がある。ほかは一気に始まって一気に終わる。
  • H3 柳… 見えているのが点ではなく線。残像を使う唯一の案。
  • H4 型抜き… 初速が乱数ではなく形から来る。散らばりに意味がある。
  • H5 文字花火… 途中で向きが逆になる。散ったものが戻ってくる。

選ぶときに効きそうな観点

  • 毎回見て飽きないか。 中くらいの達成は1日に数回出ます。 H1 と H3 は毎回わずかに違う形になるので飽きにくく、H5 は毎回同じ形です。
  • 完全制覇に回すならどれか。 H5 は文字が出るぶん一度きり向きです。 H1 は長いので、中くらいの達成には向きません。
  • 文字が読めなくならないか。 うしろの「なつやすみ おわりまで」と 課題の名前が、演出の最中も読めるかを見てください。H3 は残像が面で残るので、 ここがいちばん厳しいはずです。
  • 古い端末で重くないか。 H3 と H5 は粒が多めです。 カクつくようなら、その案は粒数を落とす設計が要ります。

まだ決めていないこと

きらきらの案は前のページのままです。花火の形が決まってから、 「中くらいの達成＝きらきら＋花火のランダム」にするのか、 「花火1本に絞る」のかを決めます。 この5案は仕組みが違うだけで、色と reduced-motion の扱いは監査ずみの共通のものを使っています。
