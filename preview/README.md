# preview/ — 検討中のサンプル置き場

採用が決まっていない案を、実機（とくにスマホ）で見るためだけに置く場所。

- **配信物ではない。** `assets/` と `index.html` からは参照しない。
  ここに何を置いても、公開版番号も内部配信番号も上げない。
- **どこからもリンクしない。** 各ページに `noindex,nofollow` を入れること。
  URL を知っている人だけが開ける状態にしておく。
- **本体の画面と間違われない書き方にする。** 冒頭に「検討用のサンプル」と
  書き、本体への戻り道を1つ置く。
- **採用・不採用が決まったら消す。** フォルダごと消してよい。

置いてよいのは、公開して困らないものだけ。合言葉、家族の記録、
個人情報、秘密情報を含むものは置かない（`AGENTS.md` の2節と同じ）。

## いま置いてあるもの

| ファイル | 中身 | 状態 |
|---|---|---|
| `anim-lab.html` | きらきら3案・完全制覇の特別演出・6テーマのコントラスト監査 | 採用案の判断待ち |
| `hanabi.html` | 花火のかたち5案（線香花火／打ち上げ／柳／型抜き／文字） | 採用案の判断待ち |
| `hikari.html` | 光り方から作り直した版（スターマイン／きらきら／ボケ玉） | 採用案の判断待ち |
| `kettei.html` | 決めた4段階（毎回／A項目／B分類／C完全制覇）＋渦の光条3種 | **いまはこれを見る** |

花火は最初の案がどれも刺さらなかったため作り直した。前の4案は
中身がぜんぶ同じ仕組み（ランダムな位置に粒がわいて消える）で、
変えていたのが数と秒数だけだったのが理由。`hanabi.html` の5案は
**粒の動きかたの仕組みから**分けてある。

結論と申し送りは `docs/completion-animation-design.md` にある。

`hikari.html` は、形ではなく **光り方** が足りなかったことが分かって
作った版。加算合成・ボケ玉・光条・暗い背景の4つを入れてある。
とくに4つめが原理の話で、**白い紙の上に加算合成で光を足しても、
白より明るい色は出せないので絶対に光らない**。背景を落とす案と
紙のままの案を切りかえて見くらべられる。

`kettei.html` が現時点の本命。利用者が決めた4段階を実際の順で組んである。
**暗転は C（完全制覇）だけ。** はんこは「できた！」と、二重の輪郭にした
「ぜんぶできた！」の2種類。渦は経路上に粒を並べ、生まれる時刻を経路の
進みに合わせてずらして「描かれていく」ように見せている。
