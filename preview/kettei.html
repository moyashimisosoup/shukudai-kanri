渦巻いていく光条（ご質問の件）

できます。仕組みは「経路の上に粒を並べ、置く時刻を経路の進みに合わせてずらす」だけです。 帯が端から端へ自分で描かれていくように見えます。上の「色」を虹にすると、 いただいた画像にいちばん近くなります。3種類つくったので、B と C にどれを使うか選んでください。

渦1

弧（画像にいちばん近い）

大きな三日月形に流れます。

画面の外から入って、大きく曲がって外へ抜けます。色が流れに沿って緑→青→紫→桃と変わります。

経路：半径いっぱいの円弧を約270度。
渦2

渦巻き

中心から外へ、ぐるぐる開きます。

内側から始まって2周半しながら広がります。いちばん「渦」らしい形です。

経路：回りながら半径が増える（アルキメデスの渦）。
渦3

二重の渦

2本が反対まわりに絡みます。

渦巻きを2本、向きと色をずらして重ねます。いちばん派手なので C 向きです。

経路：渦巻き2本を180度ずらし、片方は逆回り。

確かめていただきたいこと

この4段階でよいか

  • A は1日に何度も出ます。 項目数だけ出るので、きらきらが「またか」に ならないか。うるさければ、A も はんこだけにできます。
  • B は期間中に3回しか出ません（必須・任意・毎日）。 ここは思いきり派手でよいはずです。
  • C の暗転が長すぎないか。 いまは約6.5秒です。

はんこについて

いまの本体は、項目を終えたとき ぜんぶ できた！、 それ以外は できた！ と文字だけ変えていて、 はんこの見た目は同じです。二重の輪郭にすると、文字を読まなくても 「いつもより大きいことが起きた」と分かります。 色も傾きも変えていないので、並べても別物には見えません。

虹色について

渦の色を虹にすると画像にいちばん近くなりますが、 虹はテーマの外の色です。6テーマとも切りかえて、 浮いて見えないか確かめてください。浮くようなら「テーマの色」でも 流れは同じに出せます（色の変化がゆるやかになります）。

まだ作っていないもの

B の判定（分類ごとの完了）と A の判定（項目の完了）は、 本体では別の関数になります。4b で入れるときに、 進捗サマリーの計算（overall()）には触れずに、 判定だけ新しく足します。
